# Command Runner Plugin for Godot

Adds a dock to run expressions in the editor.
Used to manipulate the parts of the editor for debugging.

Can be used with EditorDebugger to get parts of the editor more easily.
https://github.com/Zylann/godot_editor_debugger_plugin

Use to:
Change values on objects
Open a new floating inspector
Monitor a signal and print when it is emitted.
etc
